# Tableau de bord des études cartographiques de l’AUDC
Ce dépôt privé centralise le tableau de bord de suivi des études et productions cartographiques de l’AUDC.

## Contenu  

tableau-de-bord-etudes-carto-audc.xlsx : fichier principal de suivi des études, indicateurs et productions cartographiques.

## Objectifs

suivre l’avancement des études et des cartes ;
identifier les responsables et contributeurs ;
centraliser les informations utiles au pilotage ;
améliorer la traçabilité des modifications ;
faciliter la continuité du travail entre les différents intervenants.

## Mise à jour

Avant toute modification :

- 1. télécharger la version la plus récente du fichier ;
- 2. effectuer les modifications dans Excel ;
- 3. remplacer l’ancienne version dans le dépôt ;
- 4. décrire clairement les changements dans le message de commit.

## Convention des messages de commit 

**Exemples :**

- Mise à jour des statuts d’avancement
- Ajout des indicateurs de mobilité
- Correction des responsables et échéances
- Mise à jour du tableau de bord au 12 octobre 2026
